對數的由來與符號意義

「對數」在 17 世紀由蘇格蘭數學家納皮爾所發明。
為解決繁複的天文數字運算，他將乘除轉化為加減。
例如：$2^x = 32 \implies x = 5$；
但若 $2^x = 30$，無法以有限小數精確寫出，
故定義全新符號：$x = \log_2 30$ 表示其精確解。
🕵️ 柯南破案導引：對數就是「求指數次方」！$\log_a b$ 是問：底數 $a$ 要自乘幾次方才會等於真數 $b$？
👓 名偵探推理筆記 ‧ 線索推理鏈
線索 1：歷史背景與運算簡化 17 世紀天文航海需要龐大乘除計算，納皮爾發明對數，將繁雜的「乘除運算」透過指數對應轉化為簡易的「加減運算」。
線索 2：超越整數指數的符號誕生 當 $2^x = 32 = 2^5$ 時 $x = 5$。若 $2^x = 30$，因 $2^4 = 16 < 30 < 32 = 2^5$，解必在 4 到 5 之間，記作 $x = \log_2 30$。
線索 3：雙向互換本質 指數式與對數式本質互通：底數在下方保持不變，指數與結果位置互換：$a^x = b \iff x = \log_a b$。
【CASE CLOSED 真相永遠只有一個！】$a^x = b \iff x = \log_a b$（底數在下不動，指數是求得的對數值）

對數的定義與存在條件

設 $a > 0$、$a \ne 1$ 且 $b > 0$。
若 $a^x = b$，以符號 $\log_a b$ 表示 $x$：
$a^x = b \iff x = \log_a b$
符號 $\log_a b$ 念作「以 $a$ 為底數時，$b$ 的對數」。
其中稱 $a$ 為底數，稱 $b$ 為真數。
🕵️ 柯南破案導引：1. 底數大於 0；2. 底數不能等於 1；3. 真數必須嚴格大於 0！缺少任一項對數即無意義。
👓 名偵探推理筆記 ‧ 線索推理鏈
線索 1：底數條件的來源 ($a > 0, a \ne 1$) 指數函數 $y = a^x$ 定義規定底數 $a > 0$ 且 $a \ne 1$。若 $a \le 0$，實數次方會出現虛數；若 $a = 1$，$1^x = 1$ 為常數函數，無法求出唯一的 $x$。
線索 2：真數條件的來源 ($b > 0$) 因為正數的任意次方恆為正數（$a^x > 0$），其圖形全在 $x$ 軸上方，故真數 $b = a^x$ 必須嚴格滿足 $b > 0$。
線索 3：存在條件整合檢核 任何對數式 $\log_a b$ 有意義，必須三條件同時成立：$a > 0$、 $a \ne 1$、 $b > 0$。缺一不可！
【CASE CLOSED 真相永遠只有一個！】$\log_a b$ 有意義 $\iff a > 0$ 且 $a \ne 1$（底數兩條件），且 $b > 0$（真數一條件）

對數的五大基本運算性質

設 $a, M, N$ 為正實數且 $a \ne 1$，$r, s$ 為實數且 $r \ne 0$：
1. $\log_a 1 = 0$、$\log_a a = 1$
2. $\log_{a^r} M^s = \frac{s}{r}\log_a M$
3. $\log_a M + \log_a N = \log_a (MN)$
4. $\log_a M - \log_a N = \log_a \frac{M}{N}$
5. $a^{\log_a M} = M$
🕵️ 柯南破案導引：對數相加等於真數相乘；對數相減等於真數相除；次方提出時「分子是真數次方，分母是底數次方」！
👓 名偵探推理筆記 ‧ 線索推理鏈
線索 1：基礎值與次方提出律 因 $a^0 = 1, a^1 = a$，得 $\log_a 1 = 0, \log_a a = 1$。真數次方 $s$ 提至前方分子，底數次方 $r$ 提至前方分母：$\log_{a^r} M^s = \frac{s}{r}\log_a M$。
線索 2：和差化積商律證明 令 $M = a^r, N = a^s$，則 $MN = a^{r+s}$，故 $\log_a(MN) = r + s = \log_a M + \log_a N$。同理 $\frac{M}{N} = a^{r-s}$ 導出減法公式。
線索 3：還原恆等式 若令 $\log_a M = k$，則依定義 $a^k = M$。將 $k = \log_a M$ 代回即得 $a^{\log_a M} = M$。
【CASE CLOSED 真相永遠只有一個！】同底對數加減化為真數乘除，次方提前化簡：$\log_a (MN) = \log_a M + \log_a N, \log_{a^r} M^s = \frac{s}{r}\log_a M$

對數定義與指數次方求值

設 $x = \log_{10} 5$，
試求：
$100^x + 10^{-x} = \text{？}$
🕵️ 柯南破案導引：關鍵還原：由 $x = \log_{10} 5$ 得 $10^x = 5$！再求 $100^x = (10^x)^2$ 與 $10^{-x} = \frac{1}{10^x}$！
👓 名偵探推理筆記 ‧ 線索推理鏈
線索 1：還原指數式 $x = \log_{10} 5 \iff 10^x = 5$。
線索 2：計算各項指數值 $100^x = (10^2)^x = (10^x)^2 = 5^2 = 25$；
$10^{-x} = \frac{1}{10^x} = \frac{1}{5} = 0.2$。
線索 3：兩數相加求和 $25 + \frac{1}{5} = \frac{126}{5} = 25.2$。
【CASE CLOSED 真相永遠只有一個！】$100^x + 10^{-x} = \frac{126}{5}$（或 $25.2$）

對數多項式乘法展開

試求下列各式的值：
$(\log_2 3 + \log_4 9)(\log_3 4 + \log_9 2)$
🕵️ 柯南破案導引：解題思維：先化簡各括號內的項：$\log_4 9 = \log_{2^2} 3^2 = \log_2 3$；同理化簡第二個括號！
👓 名偵探推理筆記 ‧ 線索推理鏈
線索 1：化簡第一括號 $\log_4 9 = \log_{2^2} 3^2 = \log_2 3$。
第一括號為 $\log_2 3 + \log_2 3 = 2\log_2 3$。
線索 2：化簡第二括號 $\log_3 4 = \log_3 2^2 = 2\log_3 2$；$\log_9 2 = \log_{3^2} 2 = \frac{1}{2}\log_3 2$。
第二括號為 $2\log_3 2 + \frac{1}{2}\log_3 2 = \frac{5}{2}\log_3 2$。
線索 3：相乘並利用倒數性質 $(2\log_2 3) \times (\frac{5}{2}\log_3 2) = (2 \times \frac{5}{2}) \times (\log_2 3 \times \log_3 2) = 5 \times 1 = 5$。
【CASE CLOSED 真相永遠只有一個！】原式 $= 5$

芮氏地震規模公式：求規模 $M$

【生活素養應用題】
芮氏地震規模 $M$ 和地震波所釋放的能量 $E$（單位：爾格）之關係式為：
$\log_{10} E = 11.8 + 1.5M$
若有一地震波釋放了 $10^{19.3}$ 爾格的能量，
則此地震波的芮氏規模為何？
🕵️ 柯南破案導引：將能量 $E = 10^{19.3}$ 代入關係式左邊，注意 $\log_{10} 10^{19.3} = 19.3$！
👓 名偵探推理筆記 ‧ 線索推理鏈
線索 1：將能量代入關係式左式 $\log_{10} E = \log_{10}(10^{19.3}) = 19.3$。
線索 2：列出一元一次方程式 $19.3 = 11.8 + 1.5M$。
線索 3：移項解出 M $1.5M = 19.3 - 11.8 = 7.5 \implies M = \frac{7.5}{1.5} = 5.0$。
【CASE CLOSED 真相永遠只有一個！】芮氏規模為 $5.0$（或 $5$）

921 集集大地震的芮氏規模為 $7.3$，
則其震央所釋放的能量為多少爾格？
🕵️ 柯南破案導引：將規模 $M = 7.3$ 代入右式，算出 $\log_{10} E$，再轉為指數式 $E = 10^{\text{次方}}$！
👓 名偵探推理筆記 ‧ 線索推理鏈
線索 1：將 M = 7.3 代入右式計算 $\log_{10} E = 11.8 + 1.5 \times 7.3$。
先算 $1.5 \times 7.3 = 10.95$。
線索 2：相加求得對數值 $\log_{10} E = 11.8 + 10.95 = 22.75$。
線索 3：還原為能量數值 由對數定義 $E = 10^{22.75}$ 爾格。
【CASE CLOSED 真相永遠只有一個！】釋放能量為 $10^{22.75}$ 爾格

名偵探破案密碼 ‧ 對數解密口訣錦囊

秒殺對數定義互換、運算化簡、換底連鎖與高頻避雷心法

SECRET 1

指對數互換【旋轉蝸牛法】（逆時針畫圈神技）

口訣：「從底數出發，繞過等號扛次方，最後撞向真數！」
  • 看到 $\log_a b = x$，筆尖點在底數 $a$。
  • 逆時針畫弧線繞過等號，把 $x$ 頂上去變成次方 $\implies a^x$。
  • 弧線繼續繞回左邊撞向真數 $b$ $\implies = b$。
  • 心法底氣：「底數永遠在底部，對數本質就是求次方！」
【蝸牛旋轉軌跡圖解】
$\log_{a} b = x \iff a^x = b$
例：$\log_2 8 = 3 \iff 2^3 = 8$
SECRET 2

對數四律【四字破案神訣】（押韻速記）

①「真數相乘，對數相加」
$\log_a(MN) = \log_a M + \log_a N$
合體相乘兩案卷，拆開分開用加法記！
②「真數相除，對數相減」
$\log_a(\frac{M}{N}) = \log_a M - \log_a N$
分子除以分母，拆開運算變成減法！
③「真上次頂，底下方沉」
$\log_{a^r} M^s = \frac{s}{r} \log_a M$
真數次方提到分子，底數次方掉到分母！
④「上下同底，穿透還原」
$a^{\log_a M} = M$
底數與對數底相同，瞬間抵消真數落地！
SECRET 3

換底公式【高鐵換軌法】與【骨牌連鎖律】

🚄 換底公式：樓上留樓上，樓下掉樓下！
$\log_a b = \frac{\log_c b}{\log_c a}$
原本上面的真數 $b$ 留在分子（樓上），原本下面的底數 $a$ 掉到分母（樓下）！
倒數特例：$\log_a b = \frac{1}{\log_b a}$（底真互換直接倒數！）
🀄 骨牌連鎖律：對角連連看，中間全倒光！
$\log_a b \cdot \log_b c \cdot \log_c d = \log_a d$
化為分式後，右上與左下真底互相約分，整排骨牌中間全部消去，只留下起點與終點！
